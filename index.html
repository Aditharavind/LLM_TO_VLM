How an LLM Learns to See and Answer

A language model only understands vectors, like little number messages. To turn it into a VLM, we do not rebuild the LLM. We turn a picture into picture tokens, translate them into the LLM's vector language, and place them before the words.

image 64×64patch 16×16 picture tokens 16ViT width 64 LLM width 128try it: click, drag, type
the whole trick
Picture pieces become pretend word tokens.
1. cut image into patches
2. make one vector per patch
3. translate to LLM width
4. paste before the caption words
The LLM then predicts text the normal way. It just has extra tokens at the front that came from the picture.
